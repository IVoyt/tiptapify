# פריטי סרגל הכלים {#toolbar-items}

כל פריטי סרגל הכלים הזמינים, מסודרים לפי מקטעים.

## פעולות {#actions}

| פריט     | תיאור                       |
|----------|-----------------------------|
| `undo`   | ביטול השינוי האחרון         |
| `redo`   | ביצוע מחדש של השינוי שבוטל  |

## AI {#ai}

| פריט | תיאור                                    |
|------|------------------------------------------|
| `ai` | פתיחת דיאלוג הפרומפט של ה-AI, אם הוגדר   |

## עיצוב {#format}

| פריט        | תיאור                |
|-------------|----------------------|
| `bold`      | הדלקה/כיבוי של הדגשה |
| `italic`    | הדלקה/כיבוי של נטייה |
| `underline` | הדלקה/כיבוי של קו תחתון |
| `strike`    | הדלקה/כיבוי של קו חוצה |

## עיצוב נוסף {#format-extra}

| פריט         | תיאור                                        |
|--------------|----------------------------------------------|
| `sup`        | הדלקה/כיבוי של כתב עילי                      |
| `sub`        | הדלקה/כיבוי של כתב תחתי                      |
| `code`       | הדלקה/כיבוי של קוד בתוך השורה                |
| `codeBlock`  | הוספת בלוק קוד עם הדגשת תחביר                |
| `blockquote` | הוספת ציטוט                                  |

## סגנון {#style}

| פריט             | תיאור                                      |
|------------------|--------------------------------------------|
| `heading`        | רשימה נפתחת לבחירת רמת כותרת (H1-H6)       |
| `fontFamily`     | רשימה נפתחת לבחירת משפחת גופן              |
| `fontSize`       | רשימה נפתחת לבחירת גודל גופן               |
| `lineHeight`     | הגדרת גובה שורה                            |
| `textColor`      | צבע טקסט: פלטה, צבעים אחרונים, HEX, טפטפת צבע, בורר מותאם אישית |
| `highlightColor` | צבע הדגשה: אותו בורר, עם “ללא הדגשה” בראש |

הפריט `heading` מקבל אפשרויות אחרי נקודתיים: רמות כותרת, `p` להוספת פריט פסקה, ו-`inline` להצגתם ככפתורים נפרדים במקום רשימה נפתחת:

```vue
<Tiptapify :items="['heading:p,2,3,inline', 'bold', 'italic']" />
```

## יישור {#alignment}

| פריט      | תיאור             |
|-----------|-------------------|
| `left`    | יישור הטקסט לשמאל |
| `center`  | יישור הטקסט למרכז |
| `right`   | יישור הטקסט לימין |
| `justify` | יישור הטקסט לשני הצדדים |
| `align`   | רשימה נפתחת של יישור; `align:left,center,right` מגביל את האפשרויות שלה |

## רשימות {#list}

| פריט           | תיאור                         |
|----------------|-------------------------------|
| `bulletList`   | הדלקה/כיבוי של רשימת תבליטים  |
| `orderedList`  | הדלקה/כיבוי של רשימה ממוספרת  |
| `taskList`     | הדלקה/כיבוי של רשימת משימות (תיבות סימון) |
| `indent`       | הזחת הבלוק הנוכחי פנימה       |
| `outdent`      | הזחת הבלוק הנוכחי החוצה       |

## מדיה {#media}

| פריט      | תיאור                             |
|-----------|-----------------------------------|
| `link`    | הוספה/עריכה של קישור, או של [כרטיס קישור](/he/guide/link-cards) עם `linkPreview` |
| `image`   | הוספה/עריכה של תמונה: לפי URL או העלאה, טקסט חלופי, כיתוב, גודל, מיקום |
| `video`   | הוספה/עריכה של YouTube, Vimeo או קובץ וידאו (`.mp4`, `.webm`, `.ogg`, `.mov`) |
| `iframe`  | הטמעת דף לפי כתובתו או קוד ה-iframe שלו |
| `emoji`   | פתיחת בורר אימוג'י (10 קטגוריות) |
| `charmap` | פתיחת בורר תווים מיוחדים          |
| `table`   | הוספת טבלה                        |

## שונות {#misc}

| פריט            | תיאור                                      |
|-----------------|--------------------------------------------|
| `line`          | הוספת קו אופקי                             |
| `pagebreak`     | הוספת מעבר עמוד                            |
| `source`        | מעבר לתצוגת מקור HTML גולמי ובחזרה         |
| `preview`       | מעבר למצב תצוגה מקדימה של HTML ובחזרה      |
| `fullscreen`    | מעבר למצב עריכה במסך מלא ובחזרה            |
| `formatClear`   | ניקוי כל העיצוב מהבחירה                    |
| `invisibleChar` | הוספת תווים בלתי נראים (רווחים וכו')       |

## מפרידים {#separators}

השתמשו ב-`|` כמפריד בין קבוצות כפתורים ב-prop‏ `items` בצורת מערך:

```vue
<Tiptapify
  :items="['bold', 'italic', '|', 'heading', 'bulletList', '|', 'undo', 'redo']"
/>
```

```vue
      '|',

      '|',

      '|',
      'ai',
      '|',

      '|',
      'source', 'preview', 'fullscreen'
    ]"
  />
</template>
```
