# בינאום {#internationalization}

Tiptapify תומך ביותר מ-**35 שפות** מהקופסה. התרגומים מנוהלים דרך `vue-i18n`.

## הגדרת שפת ברירת המחדל {#setting-the-default-locale}

צרו מופע `vue-i18n` והעבירו אותו בעת רישום התוסף:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## החלפת השפה בזמן ריצה {#changing-locale-at-runtime}

Tiptapify משתמש במופע `vue-i18n` שלכם — החליפו את השפה דרך `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## הוספת תרגומים מותאמים אישית {#adding-custom-translations}

Tiptapify ממזג אוטומטית את הודעות ה-locale המובנות שלו למופע `vue-i18n` שלכם כשמעבירים אותו לתוסף. אפשר להרחיב או לעקוף תרגומים לפני רישום התוסף:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

או למזג אחרי יצירת מופע ה-i18n:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## שפות RTL {#rtl-languages}

עבור שפות RTL כמו ערבית ועברית, ודאו שערכת הנושא של Vuetify תומכת ב-RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## שפה לכל מופע {#per-instance-locale}

Tiptapify משתמש ב-locale של `vue-i18n` של האפליקציה שלכם באופן גלובלי. אם אתם צריכים locales לכל מופע, השתמשו ב-scoped slots של `vue-i18n` או ב-composition API בתוך ה-scope של המופע:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
