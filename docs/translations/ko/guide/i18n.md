# 다국어 지원 {#internationalization}

Tiptapify는 **35개 이상의 언어**를 기본으로 지원합니다. 번역은 `vue-i18n`으로 관리됩니다.

## 기본 로케일 설정 {#setting-the-default-locale}

`vue-i18n` 인스턴스를 만들어 플러그인을 등록할 때 전달합니다.

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## 런타임에 로케일 변경 {#changing-locale-at-runtime}

Tiptapify는 사용자의 `vue-i18n` 인스턴스를 사용하므로 `useI18n()`으로 로케일을 변경합니다.

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## 사용자 정의 번역 추가 {#adding-custom-translations}

플러그인에 `vue-i18n` 인스턴스를 전달하면 Tiptapify가 내장 로케일 메시지를 해당 인스턴스에 자동으로 병합합니다. 플러그인을 등록하기 전에 번역을 확장하거나 덮어쓸 수 있습니다.

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

또는 i18n 인스턴스를 만든 뒤에 병합할 수도 있습니다.

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL 언어 {#rtl-languages}

아랍어 같은 RTL 언어를 사용하려면 Vuetify 테마가 RTL을 지원하도록 설정하세요.

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## 인스턴스별 로케일 {#per-instance-locale}

Tiptapify는 앱의 `vue-i18n` 로케일을 전역으로 사용합니다. 인스턴스별 로케일이 필요하면 해당 인스턴스 범위 안에서 `vue-i18n`의 스코프 슬롯이나 Composition API를 사용하세요.

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
