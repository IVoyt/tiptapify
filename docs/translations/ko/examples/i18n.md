# 다국어 지원 {#internationalization}

자세한 내용은 [다국어 지원 가이드](/ko/guide/i18n)를 참고하세요.

## 빠른 예제 {#quick-example}

런타임에 에디터 언어를 전환합니다.

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## 로케일이 서로 다른 여러 에디터 {#multiple-editors-with-different-locales}

인스턴스별로 언어를 지정하려면 `vue-i18n`의 스코프 로케일을 사용하세요.

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
