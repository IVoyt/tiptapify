# การแปลภาษา {#internationalization}

ดูรายละเอียดทั้งหมดได้ที่[คู่มือการแปลภาษา](/th/guide/i18n)

## ตัวอย่างอย่างรวดเร็ว {#quick-example}

สลับภาษาของเอดิเตอร์ขณะรันไทม์:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## เอดิเตอร์หลายตัวที่ใช้ภาษาต่างกัน {#multiple-editors-with-different-locales}

ใช้ scoped locales ของ `vue-i18n` เพื่อกำหนดภาษาแยกตามอินสแตนซ์:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
