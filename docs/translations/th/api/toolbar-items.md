# รายการบนแถบเครื่องมือ {#toolbar-items}

รายการบนแถบเครื่องมือทั้งหมดที่มี จัดตามหมวด

## การทำงาน {#actions}

| รายการ   | คำอธิบาย                    |
|----------|-----------------------------|
| `undo`   | เลิกทำการเปลี่ยนแปลงล่าสุด  |
| `redo`   | ทำซ้ำการเปลี่ยนแปลงที่เลิกทำล่าสุด |
| `resetChanges` | ยกเลิกการเปลี่ยนแปลงทั้งหมดตั้งแต่เปิดตัวแก้ไขและล้างประวัติ (ถามก่อน) |

## AI {#ai}

| รายการ | คำอธิบาย                                 |
|------|------------------------------------------|
| `ai` | เปิดกล่องโต้ตอบคำสั่ง AI หากมีการตั้งค่าไว้ |

## รูปแบบ {#format}

| รายการ      | คำอธิบาย             |
|-------------|----------------------|
| `bold`      | สลับตัวหนา           |
| `italic`    | สลับตัวเอียง         |
| `underline` | สลับขีดเส้นใต้       |
| `strike`    | สลับขีดฆ่า           |

## รูปแบบเพิ่มเติม {#format-extra}

| รายการ       | คำอธิบาย                                     |
|--------------|----------------------------------------------|
| `sup`        | สลับตัวยก                                    |
| `sub`        | สลับตัวห้อย                                  |
| `code`       | สลับโค้ดแบบอินไลน์                           |
| `codeBlock`  | แทรกบล็อกโค้ดพร้อมไฮไลต์ไวยากรณ์             |
| `blockquote` | แทรกบล็อกคำอ้างอิง                           |

## สไตล์ {#style}

| รายการ           | คำอธิบาย                                   |
|------------------|--------------------------------------------|
| `heading`        | ดรอปดาวน์เลือกระดับหัวข้อ (H1-H6)          |
| `fontFamily`     | ดรอปดาวน์เลือกแบบอักษร                     |
| `fontSize`       | ดรอปดาวน์เลือกขนาดอักษร                    |
| `lineHeight`     | ตั้งความสูงบรรทัด                          |
| `textColor`      | สีข้อความ: พาเลต สีที่ใช้ล่าสุด HEX ปากกาดูดสี ตัวเลือกสีแบบกำหนดเอง |
| `highlightColor` | สีไฮไลต์: ตัวเลือกสีเดียวกัน โดย "ไม่ไฮไลต์" อยู่ก่อน |

รายการ `heading` รับตัวเลือกหลังเครื่องหมายทวิภาค ได้แก่ ระดับหัวข้อ `p` เพื่อเพิ่มรายการย่อหน้า และ `inline` เพื่อแสดงเป็นปุ่มแยกแทนดรอปดาวน์:

```vue
<Tiptapify :items="['heading:p,2,3,inline', 'bold', 'italic']" />
```

## การจัดแนว {#alignment}

| รายการ    | คำอธิบาย          |
|-----------|-------------------|
| `left`    | จัดข้อความชิดซ้าย |
| `center`  | จัดข้อความกึ่งกลาง |
| `right`   | จัดข้อความชิดขวา  |
| `justify` | จัดข้อความเต็มบรรทัด |
| `align`   | ดรอปดาวน์การจัดแนว; `align:left,center,right` จำกัดตัวเลือก |

## รายการ {#list}

| รายการ         | คำอธิบาย                      |
|----------------|-------------------------------|
| `bulletList`   | สลับรายการแบบหัวข้อย่อย       |
| `orderedList`  | สลับรายการแบบลำดับเลข         |
| `taskList`     | สลับรายการงาน (ช่องทำเครื่องหมาย) |
| `indent`       | เพิ่มการเยื้องของบล็อกปัจจุบัน |
| `outdent`      | ลดการเยื้องของบล็อกปัจจุบัน   |

## สื่อ {#media}

| รายการ    | คำอธิบาย                          |
|-----------|-----------------------------------|
| `link`    | แทรก/แก้ไขลิงก์ หรือ[การ์ดลิงก์](/th/guide/link-cards)เมื่อใช้ `linkPreview` |
| `image`   | แทรก/แก้ไขรูปภาพ: จาก URL หรืออัปโหลด ข้อความแสดงแทน คำบรรยาย ขนาด ตำแหน่ง |
| `video`   | แทรก/แก้ไขวิดีโอ YouTube, Vimeo หรือไฟล์วิดีโอ (`.mp4`, `.webm`, `.ogg`, `.mov`) |
| `iframe`  | ฝังหน้าเว็บด้วยที่อยู่หรือโค้ด iframe |
| `emoji`   | เปิดตัวเลือกอีโมจิ (10 หมวดหมู่)  |
| `charmap` | เปิดตัวเลือกอักขระพิเศษ           |
| `table`   | แทรกตาราง                         |

## อื่น ๆ {#misc}

| รายการ          | คำอธิบาย                                   |
|-----------------|--------------------------------------------|
| `line`          | แทรกเส้นแบ่งแนวนอน                         |
| `pagebreak`     | แทรกตัวแบ่งหน้า                            |
| `source`        | สลับมุมมองซอร์ส HTML ดิบ                   |
| `preview`       | สลับโหมดตัวอย่าง HTML                      |
| `fullscreen`    | สลับโหมดแก้ไขเต็มหน้าจอ                    |
| `formatClear`   | ล้างการจัดรูปแบบทั้งหมดจากส่วนที่เลือก      |
| `invisibleChar` | แทรกอักขระที่มองไม่เห็น (ช่องว่าง ฯลฯ)     |

## ตัวคั่น {#separators}

ใช้ `|` เป็นตัวคั่นระหว่างกลุ่มปุ่มใน prop `items` แบบอาร์เรย์:

```vue
<Tiptapify
  :items="['bold', 'italic', '|', 'heading', 'bulletList', '|', 'undo', 'redo']"
/>
```
