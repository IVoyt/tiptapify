# Internacionalizācija {#internationalization}

Pilnu informāciju skatiet [internacionalizācijas ceļvedī](/lv/guide/i18n).

## Īss piemērs {#quick-example}

Mainiet redaktora valodu izpildes laikā:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Vairāki redaktori ar dažādām lokalizācijām {#multiple-editors-with-different-locales}

Katra eksemplāra valodai izmantojiet `vue-i18n` ierobežotā tvēruma lokalizācijas:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
