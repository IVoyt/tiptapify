# Internacionalizācija {#internationalization}

Tiptapify bez papildu iestatījumiem atbalsta **35+ valodas**. Tulkojumus pārvalda `vue-i18n`.

## Noklusējuma lokalizācijas iestatīšana {#setting-the-default-locale}

Izveidojiet `vue-i18n` eksemplāru un nododiet to, reģistrējot spraudni:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Lokalizācijas maiņa izpildes laikā {#changing-locale-at-runtime}

Tiptapify izmanto jūsu `vue-i18n` eksemplāru — mainiet lokalizāciju ar `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Pielāgotu tulkojumu pievienošana {#adding-custom-translations}

Kad nododat `vue-i18n` eksemplāru spraudnim, Tiptapify automātiski apvieno savus iebūvētos lokalizācijas ziņojumus ar tā ziņojumiem. Tulkojumus varat paplašināt vai pārrakstīt pirms spraudņa reģistrēšanas:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Vai apvienot pēc i18n eksemplāra izveides:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL valodas {#rtl-languages}

RTL valodām, piemēram, arābu, pārliecinieties, ka jūsu Vuetify tēma atbalsta RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Lokalizācija katram eksemplāram {#per-instance-locale}

Tiptapify globāli izmanto jūsu lietotnes `vue-i18n` lokalizāciju. Ja nepieciešamas atsevišķas lokalizācijas katram eksemplāram, izmantojiet `vue-i18n` ierobežotā tvēruma slotus vai composition API eksemplāra tvērumā:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
