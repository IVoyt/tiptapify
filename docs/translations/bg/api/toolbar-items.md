# Елементи на лентата {#toolbar-items}

Всички налични елементи на лентата, подредени по секции.

## Действия {#actions}

| Елемент  | Описание                    |
|----------|-----------------------------|
| `undo`   | Отменя последната промяна   |
| `redo`   | Връща последната отменена промяна |

## AI {#ai}

| Елемент | Описание                                 |
|------|------------------------------------------|
| `ai` | Отваря диалога за AI промпт, ако е конфигуриран |

## Форматиране {#format}

| Елемент     | Описание             |
|-------------|----------------------|
| `bold`      | Превключва получер текст |
| `italic`    | Превключва курсив    |
| `underline` | Превключва подчертаване |
| `strike`    | Превключва зачертаване |

## Допълнително форматиране {#format-extra}

| Елемент      | Описание                                     |
|--------------|----------------------------------------------|
| `sup`        | Превключва горен индекс                      |
| `sub`        | Превключва долен индекс                      |
| `code`       | Превключва код в реда                        |
| `codeBlock`  | Вмъква блок с код с подчертаване на синтаксиса |
| `blockquote` | Вмъква цитат                                 |

## Стил {#style}

| Елемент          | Описание                                   |
|------------------|--------------------------------------------|
| `heading`        | Падащо меню за избор на ниво на заглавие (H1-H6) |
| `fontFamily`     | Падащо меню за избор на шрифт              |
| `fontSize`       | Падащо меню за избор на размер на шрифта   |
| `lineHeight`     | Задава височината на реда                  |
| `textColor`      | Цвят на текста: палитра, скорошни цветове, HEX, пипета, собствен избор |
| `highlightColor` | Цвят на маркиране: същият избор, първо „Без маркиране“ |

Елементът `heading` приема опции след двоеточие: нива на заглавията, `p` за добавяне на елемент за абзац и `inline` за показването им като отделни бутони вместо падащо меню:

```vue
<Tiptapify :items="['heading:p,2,3,inline', 'bold', 'italic']" />
```

## Подравняване {#alignment}

| Елемент   | Описание          |
|-----------|-------------------|
| `left`    | Подравнява текста вляво |
| `center`  | Подравнява текста в центъра |
| `right`   | Подравнява текста вдясно |
| `justify` | Подравнява текста по ширина |
| `align`   | Падащо меню за подравняване; `align:left,center,right` ограничава опциите му |

## Списък {#list}

| Елемент        | Описание                      |
|----------------|-------------------------------|
| `bulletList`   | Превключва списък с водещи символи |
| `orderedList`  | Превключва номериран списък   |
| `taskList`     | Превключва списък със задачи (отметки) |
| `indent`       | Увеличава отстъпа на текущия блок |
| `outdent`      | Намалява отстъпа на текущия блок |

## Медия {#media}

| Елемент   | Описание                          |
|-----------|-----------------------------------|
| `link`    | Вмъква/редактира линк или [карта на линк](/bg/guide/link-cards) с `linkPreview` |
| `image`   | Вмъква/редактира изображение: по URL или качване, alt, надпис, размер, позиция |
| `video`   | Вмъква/редактира видео от YouTube, Vimeo или видеофайл (`.mp4`, `.webm`, `.ogg`, `.mov`) |
| `iframe`  | Вгражда страница по нейния адрес или iframe код |
| `emoji`   | Отваря избора на емоджи (10 категории) |
| `charmap` | Отваря избора на специални символи |
| `table`   | Вмъква таблица                    |

## Разни {#misc}

| Елемент         | Описание                                   |
|-----------------|--------------------------------------------|
| `line`          | Вмъква хоризонтална линия                  |
| `pagebreak`     | Вмъква разделител на страница              |
| `source`        | Превключва изгледа на суровия HTML код     |
| `preview`       | Превключва режима за преглед на HTML       |
| `fullscreen`    | Превключва режима на редактиране на цял екран |
| `formatClear`   | Премахва цялото форматиране от селекцията  |
| `invisibleChar` | Вмъква невидими символи (интервали и др.)  |

## Разделители {#separators}

Използвайте `|` като разделител между групите бутони в пропъртито `items` в стил масив:

```vue
<Tiptapify
  :items="['bold', 'italic', '|', 'heading', 'bulletList', '|', 'undo', 'redo']"
/>
```
