# Internasjonalisering {#internationalization}

Tiptapify støtter **35+ språk** rett ut av boksen. Oversettelsene håndteres via `vue-i18n`.

## Angi standardspråk {#setting-the-default-locale}

Opprett en `vue-i18n`-instans og send den inn når du registrerer pluginen:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Bytte språk under kjøring {#changing-locale-at-runtime}

Tiptapify bruker din `vue-i18n`-instans — bytt språk via `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Legge til egne oversettelser {#adding-custom-translations}

Tiptapify slår automatisk sammen de innebygde språkmeldingene sine med din `vue-i18n`-instans når du sender den til pluginen. Du kan utvide eller overstyre oversettelser før du registrerer pluginen:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Eller slå sammen etter at i18n-instansen er opprettet:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL-språk {#rtl-languages}

For RTL-språk som arabisk må du sørge for at Vuetify-temaet ditt støtter RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Språk per instans {#per-instance-locale}

Tiptapify bruker `vue-i18n`-språket i appen din globalt. Hvis du trenger språk per instans, bruker du `vue-i18n` sine scopede slots eller composition API innenfor instansens scope:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
