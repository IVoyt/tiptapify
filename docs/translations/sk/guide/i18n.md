# Internacionalizácia {#internationalization}

Tiptapify podporuje **viac ako 35 jazykov** hneď po inštalácii. Preklady sa spravujú cez `vue-i18n`.

## Nastavenie predvolenej lokalizácie {#setting-the-default-locale}

Vytvorte inštanciu `vue-i18n` a odovzdajte ju pri registrácii pluginu:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Zmena lokalizácie za behu {#changing-locale-at-runtime}

Tiptapify používa vašu inštanciu `vue-i18n` — lokalizáciu zmeníte cez `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Pridanie vlastných prekladov {#adding-custom-translations}

Tiptapify automaticky zlúči svoje vstavané lokalizačné správy do vašej inštancie `vue-i18n`, keď ju odovzdáte pluginu. Preklady môžete rozšíriť alebo prepísať pred registráciou pluginu:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Alebo ich zlúčte po vytvorení inštancie i18n:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Jazyky s písmom sprava doľava (RTL) {#rtl-languages}

Pre jazyky s písmom sprava doľava, ako je arabčina, zabezpečte, aby vaša téma Vuetify podporovala RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Lokalizácia pre jednotlivé inštancie {#per-instance-locale}

Tiptapify používa lokalizáciu `vue-i18n` vašej aplikácie globálne. Ak potrebujete lokalizáciu pre jednotlivé inštancie, použite scoped sloty `vue-i18n` alebo composition API v rozsahu danej inštancie:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
