# Εντολές με κάθετο {#slash-commands}

Οι εντολές με κάθετο παρέχουν ένα μενού γρήγορης εισαγωγής που εμφανίζεται όταν πληκτρολογείτε `/` στην αρχή μιας γραμμής.

## Ενεργοποίηση των εντολών με κάθετο {#enabling-slash-commands}

Οι εντολές με κάθετο είναι ενεργοποιημένες από προεπιλογή. Για να τις ελέγξετε ρητά:

```vue
<template>
  <Tiptapify
    :slash-commands="true"
    placeholder="Type / to see available commands..."
  />
</template>
```

<InteractiveEditor
placeholder="Demo εντολών με κάθετο..."
:slash-commands="true"
/>

## Διαθέσιμες εντολές {#available-commands}

Πληκτρολογήστε `/` στον επεξεργαστή για να δείτε την παλέτα εντολών. Οι διαθέσιμες εντολές περιλαμβάνουν:

| Εντολή          | Περιγραφή                                 |
|-----------------|-------------------------------------------|
| `/h1` - `/h6`   | Εισαγωγή επικεφαλίδας (επίπεδα 1-6)       |
| `/bulletList`   | Εισαγωγή λίστας με κουκκίδες              |
| `/numberedList` | Εισαγωγή αριθμημένης λίστας               |
| `/taskList`     | Εισαγωγή λίστας εργασιών                  |
| `/code`         | Εισαγωγή ενσωματωμένου κώδικα             |
| `/codeBlock`    | Εισαγωγή μπλοκ κώδικα                     |
| `/quote`        | Εισαγωγή μπλοκ παράθεσης                  |
| `/image`        | Εισαγωγή εικόνας (ανοίγει διάλογο URL)    |
| `/video`        | Ενσωμάτωση βίντεο YouTube                 |
| `/table`        | Εισαγωγή πίνακα                           |
| `/link`         | Εισαγωγή υπερσυνδέσμου                    |
| `/divider`      | Εισαγωγή οριζόντιας γραμμής               |
| `/emoji`        | Άνοιγμα επιλογέα emoji                    |
| `/specialChars` | Άνοιγμα ειδικών χαρακτήρων                |

## Πώς λειτουργεί {#how-it-works}

1. Τοποθετήστε τον δρομέα στην αρχή μιας γραμμής ή μετά από ένα κενό
2. Πληκτρολογήστε `/` — εμφανίζεται η παλέτα εντολών
3. Συνεχίστε να πληκτρολογείτε για να φιλτράρετε τις εντολές
4. Πατήστε `Enter` ή κάντε κλικ για να εισαγάγετε την επιλεγμένη εντολή

## Απενεργοποίηση των εντολών με κάθετο {#disabling-slash-commands}

```vue
<template>
  <Tiptapify
    :slash-commands="false"
    placeholder="Slash commands disabled..."
  />
</template>
```

## Εντολές με κάθετο και πλωτό μενού {#slash-commands-with-floating-menu}

Συνδυάστε τις εντολές με κάθετο με το πλωτό μενού για την καλύτερη εμπειρία επεξεργασίας:

```vue
<template>
  <Tiptapify
    :slash-commands="true"
    :floating-menu="true"
    :bubble-menu="true"
    placeholder="Full command experience..."
  />
</template>
```

- **Εντολές με κάθετο** (`/`) — ενεργοποιούνται πληκτρολογώντας `/` στην αρχή μιας γραμμής
- **Πλωτό μενού** — εμφανίζεται όταν τοποθετείτε τον δρομέα σε κενή γραμμή (προσφέρει ενέργειες σε επίπεδο μπλοκ)
- **Bubble menu** — εμφανίζεται όταν επιλέγετε κείμενο (προσφέρει ενσωματωμένη μορφοποίηση)

## Φιλτράρισμα των διαθέσιμων εντολών {#filtering-available-commands}

Μπορείτε να ορίσετε ποιες εντολές θα περιληφθούν περνώντας έναν πίνακα με αναγνωριστικά εντολών:

```vue
<template>
  <Tiptapify
    :slash-commands="['h1', 'h2', 'h3', 'bulletList', 'numberedList', 'quote']"
    placeholder="Filtered commands..."
  />
</template>
```

| `taskList`     | Λίστα εργασιών           |
| `code`         | Ενσωματωμένος κώδικας    |
| `codeBlock`    | Μπλοκ κώδικα             |
| `quote`        | Μπλοκ παράθεσης          |
| `image`        | Εικόνα                   |
| `video`        | Βίντεο YouTube           |
| `table`        | Πίνακας                  |
| `link`         | Σύνδεσμος                |
| `divider`      | Οριζόντια γραμμή         |
| `emoji`        | Emoji                    |
| `specialChars` | Ειδικοί χαρακτήρες       |
