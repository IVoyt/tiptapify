# Διεθνοποίηση {#internationalization}

Δείτε τον [οδηγό διεθνοποίησης](/el/guide/i18n) για πλήρεις λεπτομέρειες.

## Γρήγορο παράδειγμα {#quick-example}

Αλλάξτε τη γλώσσα του επεξεργαστή κατά την εκτέλεση:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Πολλαπλοί επεξεργαστές με διαφορετικές γλώσσες {#multiple-editors-with-different-locales}

Χρησιμοποιήστε τις scoped γλώσσες του `vue-i18n` για γλώσσα ανά παρουσία:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
