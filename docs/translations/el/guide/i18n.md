# Διεθνοποίηση {#internationalization}

Το Tiptapify υποστηρίζει **35+ γλώσσες** χωρίς πρόσθετη ρύθμιση. Οι μεταφράσεις διαχειρίζονται μέσω του `vue-i18n`.

## Ορισμός της προεπιλεγμένης γλώσσας {#setting-the-default-locale}

Δημιουργήστε μια παρουσία του `vue-i18n` και περάστε την κατά την καταχώριση του πρόσθετου:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Αλλαγή γλώσσας κατά την εκτέλεση {#changing-locale-at-runtime}

Το Tiptapify χρησιμοποιεί τη δική σας παρουσία του `vue-i18n` — αλλάξτε τη γλώσσα μέσω του `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Προσθήκη προσαρμοσμένων μεταφράσεων {#adding-custom-translations}

Το Tiptapify συγχωνεύει αυτόματα τα ενσωματωμένα μηνύματα γλωσσών στην παρουσία του `vue-i18n` όταν την περνάτε στο πρόσθετο. Μπορείτε να επεκτείνετε ή να παρακάμψετε μεταφράσεις πριν από την καταχώριση του πρόσθετου:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Ή να τις συγχωνεύσετε μετά τη δημιουργία της παρουσίας i18n:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Γλώσσες RTL {#rtl-languages}

Για γλώσσες RTL όπως τα Αραβικά, βεβαιωθείτε ότι το θέμα του Vuetify υποστηρίζει RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Γλώσσα ανά παρουσία {#per-instance-locale}

Το Tiptapify χρησιμοποιεί καθολικά τη γλώσσα του `vue-i18n` της εφαρμογής σας. Αν χρειάζεστε γλώσσα ανά παρουσία, χρησιμοποιήστε τα scoped slots ή το composition API του `vue-i18n` εντός του πεδίου της παρουσίας:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
