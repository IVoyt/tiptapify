# عناصر شريط الأدوات {#toolbar-items}

جميع عناصر شريط الأدوات المتاحة مرتبة حسب القسم.

## الإجراءات {#actions}

| العنصر   | الوصف                       |
|----------|-----------------------------|
| `undo`   | التراجع عن آخر تغيير        |
| `redo`   | إعادة آخر تغيير تم التراجع عنه |
| `resetChanges` | تجاهل جميع التغييرات منذ فتح المحرر ومسح السجل (يطلب التأكيد أولًا) |

## الذكاء الاصطناعي {#ai}

| العنصر | الوصف                                    |
|------|------------------------------------------|
| `ai` | يفتح نافذة طلب الذكاء الاصطناعي إذا كان مُعدًّا |

## التنسيق {#format}

| العنصر      | الوصف                |
|-------------|----------------------|
| `bold`      | تبديل النص العريض    |
| `italic`    | تبديل النص المائل    |
| `underline` | تبديل التسطير        |
| `strike`    | تبديل الشطب          |

## تنسيق إضافي {#format-extra}

| العنصر       | الوصف                                        |
|--------------|----------------------------------------------|
| `sup`        | تبديل الرمز العلوي                           |
| `sub`        | تبديل الرمز السفلي                           |
| `code`       | تبديل الشيفرة المضمّنة في السطر              |
| `codeBlock`  | إدراج كتلة شيفرة مع تلوين الصيغة             |
| `blockquote` | إدراج اقتباس                                 |

## النمط {#style}

| العنصر           | الوصف                                      |
|------------------|--------------------------------------------|
| `heading`        | قائمة منسدلة لاختيار مستوى العنوان (H1-H6) |
| `fontFamily`     | قائمة منسدلة لاختيار نوع الخط              |
| `fontSize`       | قائمة منسدلة لاختيار حجم الخط              |
| `lineHeight`     | ضبط ارتفاع السطر                           |
| `textColor`      | لون النص: لوحة ألوان، والألوان الأخيرة، وHEX، وأداة التقاط اللون، ومنتقٍ مخصص |
| `highlightColor` | لون التمييز: المنتقي نفسه، ويأتي خيار «بدون تمييز» أولًا |

يقبل العنصر `heading` خيارات بعد النقطتين الرأسيتين: مستويات العناوين، و`p` لإضافة عنصر الفقرة، و`inline` لعرضها كأزرار منفصلة بدلًا من قائمة منسدلة:

```vue
<Tiptapify :items="['heading:p,2,3,inline', 'bold', 'italic']" />
```

## المحاذاة {#alignment}

| العنصر    | الوصف             |
|-----------|-------------------|
| `left`    | محاذاة النص لليسار |
| `center`  | محاذاة النص للمنتصف |
| `right`   | محاذاة النص لليمين |
| `justify` | ضبط النص          |
| `align`   | قائمة المحاذاة المنسدلة؛ يحدّ `align:left,center,right` خياراتها |

## القوائم {#list}

| العنصر         | الوصف                         |
|----------------|-------------------------------|
| `bulletList`   | تبديل القائمة النقطية         |
| `orderedList`  | تبديل القائمة المرقّمة        |
| `taskList`     | تبديل قائمة المهام (خانات اختيار) |
| `indent`       | زيادة إزاحة الكتلة الحالية    |
| `outdent`      | تقليل إزاحة الكتلة الحالية    |

## الوسائط {#media}

| العنصر    | الوصف                             |
|-----------|-----------------------------------|
| `link`    | إدراج رابط أو تعديله، أو [بطاقة رابط](/ar/guide/link-cards) مع `linkPreview` |
| `image`   | إدراج صورة أو تعديلها: عبر رابط أو رفع، ونص بديل، وتعليق، وحجم، وموضع |
| `video`   | إدراج فيديو YouTube أو Vimeo أو ملف فيديو (`.mp4` و`.webm` و`.ogg` و`.mov`) أو تعديله |
| `iframe`  | تضمين صفحة عبر عنوانها أو عبر كود iframe الخاص بها |
| `emoji`   | فتح منتقي الرموز التعبيرية (10 فئات) |
| `charmap` | فتح منتقي الأحرف الخاصة           |
| `table`   | إدراج جدول                        |

## متنوعة {#misc}

| العنصر          | الوصف                                      |
|-----------------|--------------------------------------------|
| `line`          | إدراج خط أفقي                              |
| `pagebreak`     | إدراج فاصل صفحة                            |
| `source`        | تبديل عرض مصدر HTML الخام                  |
| `preview`       | تبديل وضع معاينة HTML                      |
| `fullscreen`    | تبديل وضع التحرير بملء الشاشة              |
| `formatClear`   | مسح كل التنسيق من التحديد                  |
| `invisibleChar` | إدراج أحرف غير مرئية (مسافات وغيرها)       |

## الفواصل {#separators}

استخدم `|` كفاصل بين مجموعات الأزرار في الخاصية `items` عند كتابتها على شكل مصفوفة:

```vue
<Tiptapify
  :items="['bold', 'italic', '|', 'heading', 'bulletList', '|', 'undo', 'redo']"
/>
```

```vue
      '|',
      'source', 'preview', 'fullscreen'
    ]"
  />

```
