# 国際化 {#internationalization}

Tiptapify は標準で **35 以上の言語**に対応しています。翻訳は `vue-i18n` で管理されます。

## デフォルトロケールの設定 {#setting-the-default-locale}

`vue-i18n` のインスタンスを作成し、プラグインの登録時に渡します。

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## 実行時のロケール変更 {#changing-locale-at-runtime}

Tiptapify はアプリの `vue-i18n` インスタンスを使うため、`useI18n()` でロケールを変更します。

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## 独自の翻訳を追加する {#adding-custom-translations}

プラグインに `vue-i18n` インスタンスを渡すと、Tiptapify は組み込みのロケールメッセージを自動的にそのインスタンスへマージします。プラグインを登録する前に、翻訳を拡張または上書きできます。

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

または、i18n インスタンスの作成後にマージします。

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL 言語 {#rtl-languages}

アラビア語などの RTL 言語では、Vuetify のテーマが RTL に対応していることを確認してください。

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## インスタンスごとのロケール {#per-instance-locale}

Tiptapify はアプリの `vue-i18n` ロケールをグローバルに使用します。インスタンスごとにロケールが必要な場合は、そのインスタンスのスコープ内で `vue-i18n` のスコープ付きスロットまたは Composition API を使用してください。

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
