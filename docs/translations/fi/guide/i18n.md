# Kansainvälistäminen {#internationalization}

Tiptapify tukee valmiiksi **yli 35 kieltä**. Käännöksiä hallitaan `vue-i18n`:n kautta.

## Oletuskielialueen asettaminen {#setting-the-default-locale}

Luo `vue-i18n`-instanssi ja anna se pluginia rekisteröitäessä:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Kielialueen vaihtaminen ajon aikana {#changing-locale-at-runtime}

Tiptapify käyttää omaa `vue-i18n`-instanssiasi — vaihda kielialue `useI18n()`:n kautta:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Omien käännösten lisääminen {#adding-custom-translations}

Tiptapify yhdistää sisäänrakennetut kielialueen viestit automaattisesti `vue-i18n`-instanssiisi, kun annat sen pluginille. Voit laajentaa tai ohittaa käännöksiä ennen pluginin rekisteröintiä:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Tai yhdistä ne i18n-instanssin luomisen jälkeen:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Oikealta vasemmalle kirjoitettavat kielet {#rtl-languages}

Oikealta vasemmalle kirjoitettavia kieliä, kuten arabiaa, varten varmista, että Vuetify-teemasi tukee RTL:ää:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Instanssikohtainen kielialue {#per-instance-locale}

Tiptapify käyttää sovelluksesi `vue-i18n`-kielialuetta globaalisti. Jos tarvitset instanssikohtaisia kielialueita, käytä `vue-i18n`:n rajattuja slotteja tai composition API:a instanssin piirissä:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
