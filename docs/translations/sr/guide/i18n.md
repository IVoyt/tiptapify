# Internacionalizacija {#internationalization}

Tiptapify podržava **35+ jezika** odmah po instalaciji. Prevodima se upravlja preko `vue-i18n`.

## Podešavanje podrazumevanog jezika {#setting-the-default-locale}

Kreirajte instancu `vue-i18n` i prosledite je prilikom registracije plugina:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Promena jezika u toku rada {#changing-locale-at-runtime}

Tiptapify koristi vašu instancu `vue-i18n` — jezik menjate preko `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Dodavanje prilagođenih prevoda {#adding-custom-translations}

Tiptapify automatski spaja svoje ugrađene poruke za jezike u vašu instancu `vue-i18n` kada je prosledite plugin-u. Prevode možete proširiti ili izmeniti pre registracije plugina:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Ili ih spojite nakon kreiranja i18n instance:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL jezici {#rtl-languages}

Za RTL jezike, poput arapskog, uverite se da vaša Vuetify tema podržava RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Jezik po instanci {#per-instance-locale}

Tiptapify koristi jezik `vue-i18n` vaše aplikacije globalno. Ako vam treba jezik po instanci, koristite scoped slotove ili composition API iz `vue-i18n` unutar opsega te instance:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
