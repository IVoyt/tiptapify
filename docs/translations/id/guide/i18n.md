# Internasionalisasi {#internationalization}

Tiptapify mendukung **35+ bahasa** langsung dari paketnya. Terjemahan dikelola melalui `vue-i18n`.

## Mengatur Locale Default {#setting-the-default-locale}

Buat instance `vue-i18n` dan berikan saat mendaftarkan plugin:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Mengganti Locale saat Runtime {#changing-locale-at-runtime}

Tiptapify menggunakan instance `vue-i18n` Anda — ganti locale melalui `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Menambahkan Terjemahan Kustom {#adding-custom-translations}

Tiptapify otomatis menggabungkan pesan locale bawaannya ke instance `vue-i18n` Anda saat Anda memberikannya ke plugin. Anda dapat memperluas atau menimpa terjemahan sebelum mendaftarkan plugin:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Atau gabungkan setelah instance i18n dibuat:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Bahasa RTL {#rtl-languages}

Untuk bahasa RTL seperti Arab, pastikan tema Vuetify Anda mendukung RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Locale per Instance {#per-instance-locale}

Tiptapify menggunakan locale `vue-i18n` aplikasi Anda secara global. Jika Anda memerlukan locale per instance, gunakan scoped slot `vue-i18n` atau composition API di dalam cakupan instance tersebut:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
