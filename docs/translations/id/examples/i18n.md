# Internasionalisasi {#internationalization}

Lihat [Panduan Internasionalisasi](/id/guide/i18n) untuk detail lengkap.

## Contoh Singkat {#quick-example}

Ganti bahasa editor saat runtime:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Beberapa Editor dengan Locale Berbeda {#multiple-editors-with-different-locales}

Gunakan locale tercakup (scoped) dari `vue-i18n` untuk bahasa per instance:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
