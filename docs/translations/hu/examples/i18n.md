# Nemzetköziesítés {#internationalization}

A részletekért lásd a [nemzetköziesítési útmutatót](/hu/guide/i18n).

## Gyors példa {#quick-example}

A szerkesztő nyelvének váltása futásidőben:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Több szerkesztő különböző nyelvekkel {#multiple-editors-with-different-locales}

A példányonkénti nyelvekhez használd a `vue-i18n` hatókörös (scoped) nyelveit:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
