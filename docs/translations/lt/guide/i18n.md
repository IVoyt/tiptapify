# Tarptautiškumas {#internationalization}

Tiptapify iš dėžės palaiko **35+ kalbų**. Vertimai valdomi per `vue-i18n`.

## Numatytosios lokalės nustatymas {#setting-the-default-locale}

Sukurkite `vue-i18n` egzempliorių ir perduokite jį registruodami įskiepį:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Lokalės keitimas vykdymo metu {#changing-locale-at-runtime}

Tiptapify naudoja jūsų `vue-i18n` egzempliorių – lokalę keiskite per `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Pasirinktinių vertimų pridėjimas {#adding-custom-translations}

Kai perduodate savo `vue-i18n` egzempliorių įskiepiui, Tiptapify automatiškai sulieja savo įtaisytus lokalės pranešimus į jį. Vertimus galite išplėsti arba perrašyti prieš registruodami įskiepį:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Arba sulieti sukūrus i18n egzempliorių:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL kalbos {#rtl-languages}

RTL kalboms, pavyzdžiui, arabų, įsitikinkite, kad jūsų Vuetify tema palaiko RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Lokalė kiekvienam egzemplioriui {#per-instance-locale}

Tiptapify naudoja jūsų programos `vue-i18n` lokalę globaliai. Jei reikia atskirų lokalių kiekvienam egzemplioriui, naudokite `vue-i18n` ribotos srities lizdus (scoped slots) arba composition API egzemplioriaus srityje:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
