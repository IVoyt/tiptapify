# Tarptautiškumas {#internationalization}

Išsamią informaciją rasite [tarptautiškumo vadove](/lt/guide/i18n).

## Trumpas pavyzdys {#quick-example}

Perjunkite redaktoriaus kalbą vykdymo metu:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Keli redaktoriai su skirtingomis lokalėmis {#multiple-editors-with-different-locales}

Kiekvieno egzemplioriaus kalbai naudokite `vue-i18n` ribotos srities lokales:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
