# टूलबार आइटम {#toolbar-items}

सेक्शन के अनुसार व्यवस्थित सभी उपलब्ध टूलबार आइटम।

## क्रियाएँ {#actions}

| आइटम     | विवरण                       |
|----------|-----------------------------|
| `undo`   | पिछला बदलाव पूर्ववत् करें    |
| `redo`   | पूर्ववत् किया बदलाव फिर से करें |
| `resetChanges` | संपादक खुलने के बाद के सभी बदलाव हटाएँ और इतिहास साफ़ करें (पहले पुष्टि माँगता है) |

## AI {#ai}

| आइटम | विवरण                                    |
|------|------------------------------------------|
| `ai` | कॉन्फ़िगर होने पर AI प्रॉम्प्ट डायलॉग खोलें |

## फ़ॉर्मैट {#format}

| आइटम        | विवरण                |
|-------------|----------------------|
| `bold`      | मोटा टेक्स्ट चालू/बंद करें |
| `italic`    | तिरछा टेक्स्ट चालू/बंद करें |
| `underline` | रेखांकन चालू/बंद करें |
| `strike`    | काटा हुआ टेक्स्ट चालू/बंद करें |

## अतिरिक्त फ़ॉर्मैट {#format-extra}

| आइटम         | विवरण                                        |
|--------------|----------------------------------------------|
| `sup`        | ऊपरी अक्षर (सुपरस्क्रिप्ट) चालू/बंद करें        |
| `sub`        | निचला अक्षर (सबस्क्रिप्ट) चालू/बंद करें         |
| `code`       | इनलाइन कोड चालू/बंद करें                      |
| `codeBlock`  | सिंटैक्स हाइलाइटिंग वाला कोड ब्लॉक डालें        |
| `blockquote` | ब्लॉककोट डालें                                |

## शैली {#style}

| आइटम             | विवरण                                      |
|------------------|--------------------------------------------|
| `heading`        | शीर्षक स्तर (H1-H6) चुनने का ड्रॉपडाउन       |
| `fontFamily`     | फ़ॉन्ट परिवार चुनने का ड्रॉपडाउन            |
| `fontSize`       | फ़ॉन्ट आकार चुनने का ड्रॉपडाउन              |
| `lineHeight`     | पंक्ति की ऊँचाई सेट करें                     |
| `textColor`      | टेक्स्ट का रंग: पैलेट, हाल के रंग, HEX, आईड्रॉपर, कस्टम पिकर |
| `highlightColor` | हाइलाइट रंग: वही पिकर, सबसे पहले "कोई हाइलाइट नहीं" |

`heading` आइटम कोलन के बाद विकल्प लेता है: शीर्षक स्तर, पैराग्राफ़ आइटम जोड़ने के लिए `p`, और उन्हें ड्रॉपडाउन के बजाय अलग-अलग बटन के रूप में दिखाने के लिए `inline`:

```vue
<Tiptapify :items="['heading:p,2,3,inline', 'bold', 'italic']" />
```

## संरेखण {#alignment}

| आइटम      | विवरण             |
|-----------|-------------------|
| `left`    | टेक्स्ट बाएँ संरेखित करें |
| `center`  | टेक्स्ट केंद्र में संरेखित करें |
| `right`   | टेक्स्ट दाएँ संरेखित करें |
| `justify` | टेक्स्ट समायोजित करें |
| `align`   | संरेखण ड्रॉपडाउन; `align:left,center,right` उसके विकल्प सीमित करता है |

## सूची {#list}

| आइटम           | विवरण                         |
|----------------|-------------------------------|
| `bulletList`   | बुलेट सूची चालू/बंद करें       |
| `orderedList`  | क्रमांकित सूची चालू/बंद करें   |
| `taskList`     | कार्य सूची (चेकबॉक्स) चालू/बंद करें |
| `indent`       | मौजूदा ब्लॉक को भीतर खिसकाएँ    |
| `outdent`      | मौजूदा ब्लॉक को बाहर खिसकाएँ    |

## मीडिया {#media}

| आइटम      | विवरण                             |
|-----------|-----------------------------------|
| `link`    | लिंक डालें/संपादित करें, या `linkPreview` के साथ [लिंक कार्ड](/hi/guide/link-cards) |
| `image`   | चित्र डालें/संपादित करें: URL या अपलोड से, alt, कैप्शन, आकार, स्थिति |
| `video`   | YouTube, Vimeo या वीडियो फ़ाइल (`.mp4`, `.webm`, `.ogg`, `.mov`) डालें/संपादित करें |
| `iframe`  | किसी पेज को उसके पते या iframe कोड से एम्बेड करें |
| `emoji`   | इमोजी पिकर खोलें (10 श्रेणियाँ)    |
| `charmap` | विशेष वर्ण पिकर खोलें             |
| `table`   | टेबल डालें                        |

## विविध {#misc}

| आइटम            | विवरण                                      |
|-----------------|--------------------------------------------|
| `line`          | क्षैतिज रेखा डालें                          |
| `pagebreak`     | पेज ब्रेक डालें                             |
| `source`        | कच्चे HTML स्रोत का दृश्य चालू/बंद करें      |
| `preview`       | HTML पूर्वावलोकन मोड चालू/बंद करें          |
| `fullscreen`    | फ़ुलस्क्रीन संपादन मोड चालू/बंद करें         |
| `formatClear`   | चयन से सारी फ़ॉर्मैटिंग हटाएँ                 |
| `invisibleChar` | अदृश्य वर्ण (स्पेस आदि) डालें                |

## विभाजक {#separators}

array-शैली के `items` prop में बटन समूहों के बीच विभाजक के रूप में `|` उपयोग करें:

```vue
<Tiptapify
  :items="['bold', 'italic', '|', 'heading', 'bulletList', '|', 'undo', 'redo']"
/>
```
