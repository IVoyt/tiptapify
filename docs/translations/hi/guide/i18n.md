# अंतर्राष्ट्रीयकरण {#internationalization}

Tiptapify **35+ भाषाओं** का समर्थन अपने-आप देता है। अनुवाद `vue-i18n` के ज़रिए प्रबंधित होते हैं।

## डिफ़ॉल्ट लोकेल सेट करना {#setting-the-default-locale}

`vue-i18n` इंस्टेंस बनाएँ और प्लगइन रजिस्टर करते समय उसे दें:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## रनटाइम पर लोकेल बदलना {#changing-locale-at-runtime}

Tiptapify आपके `vue-i18n` इंस्टेंस का उपयोग करता है — लोकेल `useI18n()` से बदलें:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## कस्टम अनुवाद जोड़ना {#adding-custom-translations}

प्लगइन को `vue-i18n` इंस्टेंस देने पर Tiptapify अपने बिल्ट-इन लोकेल संदेश उसमें अपने-आप मिला देता है। प्लगइन रजिस्टर करने से पहले आप अनुवाद बढ़ा या ओवरराइड कर सकते हैं:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

या i18n इंस्टेंस बनाने के बाद मिलाएँ:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL भाषाएँ {#rtl-languages}

अरबी जैसी RTL भाषाओं के लिए सुनिश्चित करें कि आपकी Vuetify थीम RTL का समर्थन करती है:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## प्रति-इंस्टेंस लोकेल {#per-instance-locale}

Tiptapify आपके ऐप के `vue-i18n` लोकेल को वैश्विक रूप से उपयोग करता है। अगर आपको प्रति-इंस्टेंस लोकेल चाहिए, तो इंस्टेंस के स्कोप के भीतर `vue-i18n` के स्कोप्ड स्लॉट या composition API उपयोग करें:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
