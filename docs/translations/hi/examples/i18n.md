# अंतर्राष्ट्रीयकरण {#internationalization}

पूरी जानकारी के लिए [अंतर्राष्ट्रीयकरण गाइड](/hi/guide/i18n) देखें।

## त्वरित उदाहरण {#quick-example}

रनटाइम पर एडिटर की भाषा बदलें:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## अलग-अलग लोकेल वाले कई एडिटर {#multiple-editors-with-different-locales}

हर इंस्टेंस की अलग भाषा के लिए `vue-i18n` के स्कोप्ड लोकेल का उपयोग करें:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
