# Çok Dillilik {#internationalization}

Tüm ayrıntılar için [Çok Dillilik Kılavuzuna](/tr/guide/i18n) bakın.

## Hızlı Örnek {#quick-example}

Düzenleyici dilini çalışma zamanında değiştirin:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Farklı Yerel Ayarlara Sahip Birden Fazla Düzenleyici {#multiple-editors-with-different-locales}

Örnek başına dil için `vue-i18n`'in kapsamlı yerel ayarlarını kullanın:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
