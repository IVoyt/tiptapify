# Интернационализация {#internationalization}

Tiptapify поддерживает **более 35 языков** из коробки. Переводы управляются через `vue-i18n`.

## Установка локали по умолчанию {#setting-the-default-locale}

Создайте экземпляр `vue-i18n` и передайте его при регистрации плагина:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Смена локали во время работы {#changing-locale-at-runtime}

Tiptapify использует ваш экземпляр `vue-i18n` — меняйте локаль через `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Добавление собственных переводов {#adding-custom-translations}

Tiptapify автоматически добавляет свои встроенные сообщения локалей в ваш экземпляр `vue-i18n`, когда вы передаёте его плагину. Вы можете расширить или переопределить переводы до регистрации плагина:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Или объединить их после создания экземпляра i18n:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL-языки {#rtl-languages}

Для RTL-языков, например арабского, убедитесь, что ваша тема Vuetify поддерживает RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Локаль для отдельного экземпляра {#per-instance-locale}

Tiptapify глобально использует локаль `vue-i18n` вашего приложения. Если нужны локали для отдельных экземпляров, используйте scoped-слоты `vue-i18n` или composition API в области видимости экземпляра:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
