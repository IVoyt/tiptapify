# Internacionalizacija {#internationalization}

Tiptapify takoj po namestitvi podpira **več kot 35 jezikov**. Prevodi se upravljajo prek `vue-i18n`.

## Nastavitev privzetega jezika {#setting-the-default-locale}

Ustvarite primerek `vue-i18n` in ga podajte ob registraciji vtičnika:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Spreminjanje jezika med izvajanjem {#changing-locale-at-runtime}

Tiptapify uporablja vaš primerek `vue-i18n` — jezik spremenite prek `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Dodajanje lastnih prevodov {#adding-custom-translations}

Tiptapify svoja vgrajena sporočila jezikov samodejno združi z vašim primerkom `vue-i18n`, ko ga podate vtičniku. Prevode lahko razširite ali prepišete pred registracijo vtičnika:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Ali jih združite po ustvarjanju primerka i18n:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Jeziki RTL {#rtl-languages}

Za jezike RTL, kot je arabščina, poskrbite, da vaša tema Vuetify podpira RTL:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Jezik za posamezen primerek {#per-instance-locale}

Tiptapify globalno uporablja jezik `vue-i18n` vaše aplikacije. Če potrebujete jezike za posamezne primerke, uporabite odsekane reže (scoped slots) ali Composition API knjižnice `vue-i18n` znotraj dosega primerka:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
