# Rahvusvahelistamine {#internationalization}

Tiptapify toetab karbist välja **üle 35 keele**. Tõlkeid haldab `vue-i18n`.

## Vaikekeele määramine {#setting-the-default-locale}

Loo `vue-i18n` instants ja anna see plugina registreerimisel kaasa:

```typescript
// main.ts
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## Keele muutmine käitusajal {#changing-locale-at-runtime}

Tiptapify kasutab sinu `vue-i18n` instantsi — muuda keelt funktsiooniga `useI18n()`:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', label: 'English' },
  { code: 'de', label: 'Deutsch' },
  { code: 'fr', label: 'Français' },
  { code: 'es', label: 'Español' },
  { code: 'ru', label: 'Русский' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="label"
      item-value="code"
      label="Language"
    />

    <Tiptapify placeholder="Start writing..." />
  </div>
</template>
```

## Kohandatud tõlgete lisamine {#adding-custom-translations}

Tiptapify liidab oma sisseehitatud keelesõnumid automaatselt sinu `vue-i18n` instantsi, kui annad selle pluginale kaasa. Tõlkeid saad laiendada või üle kirjutada enne plugina registreerimist:

```typescript
import { createI18n } from 'vue-i18n'
import TiptapifyPlugin from 'tiptapify'
import 'tiptapify/style.css'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  messages: {
    // Custom translations take precedence over Tiptapify's built-in ones
    en: {
      toolbar: {
        bold: 'Make bold',
        italic: 'Make italic',
      },
    },
  },
})

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

Või liida need pärast i18n instantsi loomist:

```typescript
const i18n = createI18n({
  legacy: false,
  locale: 'en',
})

i18n.global.mergeLocaleMessage('en', customTranslations)

app.use(i18n)
app.use(TiptapifyPlugin, { i18n })
```

## RTL-keeled {#rtl-languages}

RTL-keelte, näiteks araabia keele puhul veendu, et sinu Vuetify teema toetab RTL-i:

```typescript
const vuetify = createVuetify({
  locale: {
    rtl: true,
  },
})
```

## Instantsipõhine keel {#per-instance-locale}

Tiptapify kasutab sinu rakenduse `vue-i18n` keelt globaalselt. Kui vajad instantsipõhiseid keeli, kasuta `vue-i18n`i skoopitud pesasid või composition API-t instantsi skoobis:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n({ useScope: 'local' })
</script>

<template>
  <Tiptapify :placeholder="t('editor.placeholder')" />
</template>
```
