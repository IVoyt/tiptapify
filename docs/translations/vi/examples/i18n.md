# Đa ngôn ngữ {#internationalization}

Xem [Hướng dẫn đa ngôn ngữ](/vi/guide/i18n) để biết chi tiết.

## Ví dụ nhanh {#quick-example}

Chuyển đổi ngôn ngữ của trình soạn thảo khi đang chạy:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Nhiều trình soạn thảo với các ngôn ngữ khác nhau {#multiple-editors-with-different-locales}

Dùng các locale có phạm vi (scoped) của `vue-i18n` để đặt ngôn ngữ riêng cho từng instance:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
