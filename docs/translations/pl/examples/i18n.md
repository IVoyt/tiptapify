# Internacjonalizacja {#internationalization}

Szczegóły znajdziesz w [przewodniku po internacjonalizacji](/pl/guide/i18n).

## Krótki przykład {#quick-example}

Zmień język edytora w czasie działania aplikacji:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'en', name: 'English' },
  { code: 'de', name: 'Deutsch' },
  { code: 'fr', name: 'Français' },
  { code: 'es', name: 'Español' },
]
</script>

<template>
  <div>
    <v-select
      v-model="locale"
      :items="languages"
      item-title="name"
      item-value="code"
      label="Language"
    />

    <Tiptapify />
  </div>
</template>
```

## Wiele edytorów z różnymi ustawieniami regionalnymi {#multiple-editors-with-different-locales}

Użyj lokalnych ustawień regionalnych (scoped locales) `vue-i18n`, aby ustawić język osobno dla każdej instancji:

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const en = useI18n({ useScope: 'local', locale: 'en' })
const de = useI18n({ useScope: 'local', locale: 'de' })
</script>

<template>
  <v-row>
    <v-col>
      <h3>English</h3>
      <Tiptapify />
    </v-col>
    <v-col>
      <h3>German</h3>
      <Tiptapify />
    </v-col>
  </v-row>
</template>
```
